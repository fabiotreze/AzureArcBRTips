# Changelog – Arc Agent Support Workbook
|Version|Date|Description|
|---|---|---|
|v4.5.0|2026-10-25|- **Security floor** (parameter, default 1.61 – known agent elevation-of-privilege CVEs, aligned with *Arc Posture Review*): new KPI tile, *SecurityFloor* column in inventory and auto-upgrade detail (below-floor servers listed first), upgrade-path action *Upgrade now (below security floor)*; reference line, legend and methodology updated.|
|v4.4.0|2026-10-25|- **Logic fixes from end-to-end review**: OS / Connection status / Auto upgrade filters now applied to Advisor, Policy and Extensions (were ignored); Advisor totals respect filters; Advisor freshness column (status changed after recommendation).<br>- Policy: Exempt/Unknown no longer counted as compliant (new *OtherMachines*).<br>- Extension issues: multi-line messages parsed, boilerplate removed, run/scope IDs normalised so identical causes group together.<br>- Latest: fallback to the auto-upgrade target of the other OS when an OS has none (avoids relying on the unstable catalog API); unknown agent version no longer shown as *Lagging*.|
|v4.3.0|2026-10-25|- **Extension issues (generic, any extension)**: IssueCategory (Failure / Health warning / In progress / OK) and Issue (root-cause phrase + exit code, or health issues reported by the extension) parsed from the extension status – no extension names or error catalog in the workbook.<br>- New table *Extension issues – all extensions, grouped by cause*; per-server comparison sorted failures first.|
|v4.2.0|2026-10-25|- **Fix**: per-server extension comparison blocked after switching extension (stale multi-select parameter) – version list now also read as a single value and the parameter is optional.<br>- *Published by Azure* list built in Resource Graph: numeric version sort (1.0.16.6 above 1.0.9.2), machines per version, installed versions no longer offered.|
|v4.1.0|2026-10-25|- Extensions: clicking a published version sets it as **comparison target** for the per-server table (Target / BehindTarget / At or above target / Below target); click again to return to latest. Compact height for the extensions grid.|
|v4.0.0|2026-10-25|- **Section order** follows the analysis flow: Overview → Distribution → Advisor (blockers) → Inventory → Automatic upgrade → Manual upgrade paths & downloads → Policy → Extensions → Methodology & sources; sections numbered; intro aligned.|
|v3.9.0|2026-10-25|- Layout: small tables use compact height (no blank area under *Latest reference*); reference line split into short bullets; legend split into two side-by-side compact tables.|
|v3.8.0|2026-10-25|- Fix: translated titles failed under Resource Graph throttling – titles are now bilingual caption blocks (no extra queries).<br>- Legend rendered as plain markdown (HTML details/summary not supported).|
|v3.7.0|2026-10-25|- **Self-explanatory & bilingual (EN/PT)**: Language selector; always-visible intro (what it answers / how to use) and *reference in use* line with disclaimer; legend with meaning and action per status; one-line purpose per section; translated titles, KPI tiles and footer.<br>- Column names harmonised (Latest, LatestPublished, VersionFreshness); catalog-match column removed from inventory; changelog moved to Edit mode.|
|v3.6.0|2026-10-25|- Layout: *Latest reference per OS* (40%, 6 columns) and *Installed versions → latest* (60%, 7 columns) side by side under one header; catalog download tables appear only when the API has versions ≥ the oldest agent in the fleet.|
|v3.5.0|2026-10-25|- **Extensions compliance (dynamic)**: fleet view per publisher/type (auto-upgrade coverage, versions in use, failures) with click-through to the versions Azure publishes (Extension Metadata V2 API) and a per-server comparison (Latest / Behind / No longer offered, auto-upgrade outlook).|
|v3.4.0|2026-10-25|- Compact *Upgrade paths & download options*: one row per installed version (replaces the per-catalog-entry table); catalog downloads filtered from the oldest fleet version upwards and hidden for OSes with no machines.<br>- Settings parameters shown only in Edit mode (cleaner header).|

|v3.2.0|2026-10-25|- Removed curly-brace placeholders from text blocks (were parsed as parameters → UNTRUSTED_PARAM / external-link prompt).<br>- LastAttemptStatus normalised (success → Success) so icons apply.<br>- Titles aligned with the latest-reference model; note on catalog API variability.|
|v3.1.0|2026-10-25|- **Fix**: ParserFailure in *Official latest vs fleet*.<br>- **Latest model**: catalog API proved paged/incomplete (did not return 1.68) – latest now = max(Azure auto-upgrade target, catalog API, optional fleet max, optional override) with *LatestSource* column.<br>- Versions behind = sequential minor distance; per-machine catalog join simplified (no row explosion).<br>- Policy: per-machine de-duplication, initiative reference ID as readable name.|
|v3.0.0|2026-10-25|- **Official source of truth**: latest/catalog read from ARM the agent catalog API per OS (Windows/Linux) instead of the fleet maximum.<br>- Versions behind = count of newer official releases; catalog match column (listed / older / newer / gap) and catalog sanity check.<br>- Auto-upgrade: eligibility (min version parameter), health (On track / Lagging / Failing / Blocked), desired vs official latest, last attempt details.<br>- New sections: Azure Advisor (Arc recommendations, cross-check with version status), Azure Policy compliance, VM extensions, data freshness.<br>- Dynamic OS and connection-status filters; all thresholds exposed as parameters; KPI tiles consolidated in one query.<br>- Fix: notes/changelog were permanently hidden (referenced non-existent parameters).|
